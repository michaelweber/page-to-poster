# Kit reference

Generated by `python tools/kit_reference.py` from the docstrings in `mapkit/blender/kit.py`. [props.md](props.md) explains how to use these; the picture there shows every ready-made prop.

Units are meters, +x is east, +y is north, the floor is z = 0, and angles are radians (`math.radians(90)` or `math.pi / 2`). `from mapkit.blender.kit import *` also gives a props module `math`, `random`, and the light colors `WARM` and `RED`.

## Decals and lights

Decals are ink stickers from the project's `decals/` folder.

| Call | What it makes |
|---|---|
| `decal(name, x, y, z=0.0, size=1.0, rot=0.0, color=None)` | Lay the ink sticker decals/&lt;name&gt;.png flat on a surface at (x, y, z), `size` meters across. A decal whose image is missing is skipped (returns None), so props can ask for decals that only some projects generate. |
| `wall_decal(name, room, side, along, z, size, color=None)` | Vertical decal on the inner face of a room wall (decal plane rotated 90 deg to face into the room). |
| `lamp(name, kind, loc, energy, color=(1.0, 1.0, 1.0), rot=(0.0, 0.0, 0.0), spot_deg=40.0, radius=0.15, map_dim=1.0)` | A practical light (kind POINT, SPOT or AREA; energy in watts). Map and poster renders multiply its energy by `map_dim`: use a small value for lights sized for a dark interior that would wash out the lit map view. |

## Basics

The mesh builder, transforms, named features and your own materials.

| Call | What it makes |
|---|---|
| `material(name, color, tex=None, scale=2.0, rough=0.8, metal=0.0, emit=0.0, bump=0.3)` | Register a material for this build. `tex` is a texture key (textures/&lt;tex&gt;.png in the project) or None; `scale` is how many meters one texture tile covers. A strongly red `color` prints in the poster's accent ink. |
| `feat(name, x, y, z=0.0)` | Name the point (x, y, z) so poster.json can hang a callout on it. Use "&lt;room id&gt;.&lt;what&gt;" names. |
| `T(x=0.0, y=0.0, z=0.0, rz=0.0, rx=0.0, ry=0.0, s=None)` | Transform: move to (x, y, z), then turn by rz about the vertical (and rx, ry), then scale by s. Chain frames with @, as in T(5, 2, 0, rz=0.5) @ T(ry=0.3). Pass the result as a primitive's M. |
| `Rz(a)` | Turn by `a` radians about the vertical. |
| `inst(me, collection, M, name=None)` | Place a copy of mesh `me` (from MB.mesh() or a *_mesh() helper) at transform M. |

### `MB`

Mesh builder: primitives add closed solids (several materials) to it; obj() turns it into one object. mb = MB("r3_props"); box(mb, "wood", ...); cyl(mb, "rust_metal", ...); mb.obj(P) Use one MB per group of things that belong together. An MB that stays empty makes no object.

| Method | What it does |
|---|---|
| `mesh(self)` | The collected solids as a mesh, for placing many copies with inst(). |
| `obj(self, collection, name=None, nocap=False)` | Add the collected solids to `collection` (a room's P) as one object. nocap=True keeps the cutaway from slicing it (walkable surfaces such as stairs and ramps). |

### `Rect`

A room (or a corridor junction): the rectangle minx..maxx, miny..maxy of clear floor, ceiling height `h` and wall top `top`. Room functions get one as `r` and place props relative to it (r.cx, r.cy, r.minx, ...).

| Method | What it does |
|---|---|
| `rand(self, rng, margin=1.0)` | A random floor point at least `margin` meters from the walls. |
| `on_boundary(self, p, tol=0.05)` | True when 2D point p lies on the room's edge. |
| `side_of(self, p)` | (wall letter nearest to p, p's coordinate along that wall). |
| `add_opening(self, p, width, z0, z1, toward=None)` | Cut a doorway `width` wide from height z0 to z1 in the wall at p. |
| `inner_face(self, side, along, inset=0.012)` | 2D point just inside wall `side` at coordinate `along`, for fixing things to the wall. |

## Primitives

Closed solids to build anything the ready-made props do not cover. `mat` is a material name; `M` is an optional transform.

| Call | What it makes |
|---|---|
| `box(mb, mat, c, s, M=None)` | Box centred on c = (x, y, z) with size s = (sx, sy, sz). |
| `boxmm(mb, mat, lo, hi, M=None)` | Box from corner lo = (x0, y0, z0) to corner hi = (x1, y1, z1). |
| `prism(mb, mat, poly, z0, z1, M=None)` | Extrude the polygon `poly` (a list of (x, y)) from height z0 to z1. |
| `loft(mb, mat, rings, M=None)` | Skin a stack of rings (each a list of the same number of (x, y, z) points) and cap both ends. |
| `ring(r, z, n, cx=0.0, cy=0.0, phase=0.0, sx=1.0, sy=1.0)` | n points on a circle of radius r at height z (an ellipse with sx, sy), for loft(). |
| `cyl(mb, mat, c, r, h, n=16, M=None)` | Upright cylinder: base centre c = (x, y, z), radius r, height h, n sides. |
| `frustum(mb, mat, c, r0, r1, h, n=16, M=None, phase=0.0)` | Upright cone section: radius r0 at the base c, r1 at the top, height h. |
| `sqfrustum(mb, mat, c, s0, s1, h, M=None)` | Square frustum: side s0 at the bottom, s1 at the top. |
| `tube(mb, mat, c, rin, rout, z0, z1, n=24, M=None)` | Upright ring or pipe section around c = (x, y): inner radius rin, outer rout, from height z0 to z1. |
| `dome(mb, mat, c, r, h, n=16, rings_=5, M=None)` | Closed dome (flat base at c.z, height h). |
| `arc_slab(mb, mat, cx, cy, rin, rout, a0, a1, z0, z1, step=0.14)` | Curved slab: the part of a ring (rin..rout around cx, cy) between angles a0 and a1, from z0 to z1. |
| `arc_pts(cx, cy, r, a0, a1, z, step=0.12)` | Points along an arc at height z, for railing() or sweep(). |
| `xprism(mb, mat, poly_yz, x0, x1, M=None)` | Extrude the profile `poly_yz` (a list of (y, z)) along x from x0 to x1: wedges, ramps, gutters. |
| `sweep(mb, mat, pts, r, n=6, M=None)` | Round bar of radius r through the 3D points `pts`: pipes, rails, cables, bars. |
| `chamfer(pts, d)` | Cut the corners of a 3D polyline back by d, so a sweep() through it bends instead of kinking. |
| `blob(mb, mat, c, rad, rng, jit=0.25, rz=0.0, M=None)` | Lumpy boulder centred on c with radii rad = (rx, ry, rz): rubble, rock, sacks, organic lumps. jit is how irregular it is (0 to about 0.4). |
| `flat_blob(mb, mat, cx, cy, r, z0, z1, rng, n=14, irr=0.35, sx=1.0, sy=1.0, rot=0.0, M=None)` | Irregular flat patch about r across from height z0 to z1: puddles of dirt, flakes, rugs, moss. |
| `stairs(mb, mat, x, y, ang, width, n, rise, run, z0=0.0, base=None, M=None)` | Solid flight: bottom front edge centred on (x, y), climbing along heading `ang`. |
| `railing(mb, mat, pts, h=1.05, r=0.03, spacing=1.4, M=None)` | Handrail + mid rail along base points pts (3D), posts every `spacing`. |
| `panel(mb, mat, M, length, z0, z1, thick, holes=(), y0=0.0)` | Wall panel in frame M: x 0..length, y y0..y0+thick, z z0..z1, rectangular holes (x0, x1, z0, z1). |

## Paths

Helpers for polylines of (x, y) points: conveyor lines, pipes along a wall, trails.

| Call | What it makes |
|---|---|
| `seglen(a, b)` | Length of the 2D segment a-b. |
| `trim_start(path, d)` | The path with d meters cut off its first segment. |
| `trim_end(path, d)` | The path with d meters cut off its last segment. |
| `path_len(path)` | Length of a 2D polyline. |
| `path_at(path, s)` | Point and unit tangent at arc length s. |
| `project(path, p)` | Nearest point on a polyline to p: (distance, point, unit tangent, arc length along the path). |
| `dist_poly(path, p)` | Distance from point p to a polyline. |
| `offset_pts(path, o)` | The polyline moved sideways by o meters (positive: to its left), with mitred corners. |
| `strip(mb, mat, path, oa, ob, z0, z1)` | Band along a polyline between sideways offsets oa and ob, from height z0 to z1: floors, kerbs, walls, conveyor beds, carpets. |
